Kit V2 Animation

Export to MP4

Video export runs in the terminal (not in the browser preview). From the kit-v2-animation folder:

  1. Install once: npm install
  2. Export 1080p: npm run render
Resolution
1920 × 1080
Frame rate
30 fps
Duration
10 seconds (300 frames)
Output file
out/kit-v2-1080p.mp4

First run downloads Playwright Chromium (~2 min). Capture + encode takes ~3–5 min.
